# About the project

- **Main focus**: Learn more about JavaFX.
- **What is the project?**: A simplified JavaFX project that displays registered people in a list.
- **Where does the foundation come from?**: From Professor Nelio Alves Java course hosted on the Udemy platform, Section 25.
- **What was learned?**: JavaFX fundamentals, such as key imports and working with Scene Builder.
